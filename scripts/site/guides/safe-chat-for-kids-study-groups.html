What "safe" can and cannot mean for a kids' study chat

If you are a parent or teacher looking for a place where a handful of kids can do homework together over voice and text, you probably worry about the same things most adults do: strangers finding the children, an app collecting data about them, and conversations that nobody can see. No app can make a child safe on its own, and it is wise to be wary of any app that says it can. What a tool can do is remove certain risks by design and be honest about the rest.

This guide explains which risks howlden removes, which ones it does not, and how to set up a small study group so the adults stay in charge. howlden is a free, open source chat, voice and video app that runs in the browser. It has no accounts and no servers of its own that carry conversations: members connect directly to each other. It has not been through any child safety certification, and it has no moderators, content filters or parental controls. It is simply a small, private room that only invited people can enter.

The risks the design takes away

  • No strangers wandering in. A den, howlden's word for a group space, is invite only. There is no public directory, no search, no "people you may know" list and no way to message someone who is not already in your den.
  • No account data to leak. Kids do not give an email, phone number, birthday or password. They pick a display name and an avatar, and those live only in their own browser.
  • No ads and no tracking. There is no howlden backend, no database and no analytics. The website is static files on GitHub Pages.
  • Private conversations. Voice, video, text and files travel end to end encrypted between the browsers in the den. No server of ours ever sees them.
  • A small room by design. A den holds up to 5 people, which happens to be a comfortable size for a study group and too small to turn into a crowd.

What it does not do, plainly

The same design that keeps outsiders away also means some things parents may expect are simply not there:

  • No adult dashboard. Because nothing is stored online, there is no server copy of the chat for a parent or teacher to review later. If you want to know what was said, be in the den or near the device.
  • No age check. howlden never asks anyone's age, so it cannot verify it.
  • Members can invite. Any member can create an invite. The app does not stop a child from inviting a friend, so you need a house rule about it.
  • Nothing stops a screenshot. Anyone in a den can copy, photograph or record what they see, as with any chat.
  • Everyone has to be online together. There is no mailbox holding messages for kids who join later. For study groups this is usually fine, since sessions happen at a set time anyway.

Before using any chat tool with students, check your school's rules on online tools and the minimum ages that apply where you live. Some schools only allow approved platforms for class activities, and that decision belongs to them.

Setting up a study den the careful way

The safest pattern is simple: an adult creates the den and is the only person who sends invites.

  1. The adult opens the app and creates a den, for example "Thursday math group". Add a text channel for questions, one for sharing worksheets, and a voice channel called something like "homework table".
  2. Set a passphrase. howlden can add a second layer of encryption to messages and files, readable only by people who know the passphrase. Give it to parents directly, not inside the den.
  3. Invite through the parents. Create an invite for each child and send it to that child's parent through a messenger you already use with the family. The parent opens it on the child's device, and the browser makes a short reply code that comes back to you the same way. If you are together in a classroom, scanning the QR code works too.
  4. Compare the fingerprint. howlden shows a short connection fingerprint. Reading it aloud on the first call confirms you are really connected to that family and nobody is in between.
  5. Agree on ground rules with the kids during the first session.

Each invite is an exchange between you and one family, so send it privately and never post it in a big group chat or on a class page.

Ground rules that actually help

Technology covers part of the job, and habits cover the rest. These work well for study groups:

  • Only the adult invites. If a kid wants to add a classmate, they ask, and the adult arranges it with that child's parent.
  • Use first names or nicknames as display names, never full names, school names or ages.
  • For younger kids, the device stays in a shared room like the kitchen table, with the volume up, and an adult checks in now and then. Supervision still matters in a private room.
  • Cameras are optional. Voice plus screen sharing is usually enough to work through a problem, and it uses much less bandwidth than video.
  • Files are for schoolwork. Shared files go straight from browser to browser, so remind kids to open only what they were expecting.
  • If anything feels wrong, the rule is to leave the call and tell an adult, with no trouble for speaking up.

The features a study group will actually use

A typical session looks like this. Everyone joins the voice channel at the agreed time, and a ring lights up around whoever is speaking, so it is easy to see who has the floor. A student stuck on a fractions problem shares their screen, a friend walks through it, and the adult can mute or deafen when stepping away for a moment. Text channels hold the quick stuff: a link to the reading, a photo of a worksheet, a spoiler tag over an answer so others can try first, and reactions instead of a flood of "ok" messages.

Because it runs in a browser, it works on the laptops and phones families already have. Nothing to install also means no extra app store accounts for the kids. School networks are the one technical snag: some block direct connections, and if both sides are on strict networks a call can fail. The guide to fixing a failed WebRTC connection explains the options, and joining from home is often enough.

Do a test run first

Before the first real session, do a ten minute test with another parent or a colleague: open a den, send an invite, swap the reply code, compare the fingerprint and try a short voice call. You will know exactly what the kids will see. For more background, read about chatting without signing up and about private group voice calls. When it feels right, set up your study den and keep the adults in the loop.
