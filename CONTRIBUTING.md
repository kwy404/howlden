# Contributing to howlden

Thanks for helping the pack. howlden is a static web app: no backend, no accounts, no analytics. Contributions keep it that way.

## Getting started

```bash
git clone https://github.com/kwy404/howlden.git
cd howlden
npm install
npm test
npm run serve   # http://127.0.0.1:8080/
```

Node 18.18 or newer is required for the tooling. The app itself runs in any current browser.

## Where things live

| Path | What it is |
| --- | --- |
| `src/` | Shared modules (QR encoder, invite codes, crypto, identity, mesh, history, WebRTC links), tested with Vitest. `npm run core` copies them to `docs/app/core/`. |
| `docs/app/` | The app: HTML, CSS, UI modules, the service worker and the manifest. |
| `docs/` (other pages) | The website, generated by `npm run site` from `scripts/site/`. Do not edit the generated HTML by hand. |
| `scripts/site/guides/` | Guide sources: a JSON meta comment, then the sections. Portuguese guides live in `scripts/site/guides/pt/`. |
| `scripts/site/*.mjs` | Site layout, landing page, guide pages, and all the art (Luna, the pack, icons, scenes), drawn in code. |
| `assets/` | Exported art for the README and the social preview. |
| `test/` | `unit-*` for the core modules, `app-*` for the app, `site-*` for the website. |

## Before you open a pull request

Run every check CI runs:

```bash
npm run lint
npm run rules
npm run core:check
npm test
npm run site:check
```

If you changed anything in `scripts/site/`, run `npm run site` and commit the regenerated files. If you changed a page title or a guide hero, run `npm run site:images` to refresh the Open Graph images (it needs a local Chromium based browser).

## House rules

- No emoji and no en or em dash characters in any file (`npm run rules` checks this).
- Do not name other CSS frameworks; the site is styled with [Monsoon](https://kwy404.github.io/monsoon/) and made interactive with [Voodoo.js](https://kwy404.github.io/Voodoo.js/).
- Keep security wording true. Say what WebRTC, DTLS, the passphrase layer and TURN relays really do. Never claim "impossible to hack" or "anonymous".
- No tracking, analytics, remote fonts in the app, or calls to servers other than STUN and the TURN servers a user configures.
- Keep the honest limits visible: up to 8 per den, everyone online, strict NAT needs TURN.
- Art is original. Do not copy brand assets.

## Writing a guide

Copy an existing file in `scripts/site/guides/`, keep the meta fields (slug, title up to 65 characters, description of 140 to 160 characters, h1, lede, short, icon, scene, keywords, faq) and write at least 800 words. Add the slug to `ORDER` in `scripts/site/build-site.mjs`, then run `npm run site` and `npm test`.

## Reporting bugs

Open an issue with the browser and version, what you did, what you expected and what happened. For connection problems, say whether both sides were on the same network. For security issues, follow [SECURITY.md](https://github.com/kwy404/howlden/blob/main/SECURITY.md) instead.
